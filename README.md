# Lily-Blade · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 登录游戏**：自动进入游戏
- **📧 领取邮件奖励**：领取邮箱内所有奖励
- **⚔️ 刷体力第一次**：默认记忆巡回，可自定义选择副本
- **⚔️ 刷体力第二次**：默认实战训练，可自定义选择副本
- **⚔️ 刷体力第三次**：默认星辰试炼，可自定义选择副本
- **⚔️ 荣耀之战一次**：自动完成一次荣耀之战
- **📋 领取每日任务奖励**：领取每日任务奖励
- **🌾 丰饶之角奖励领取**：领取丰饶之角奖励

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
